# Named Eden Musk bottle labels

The final product images are `eden-musk-NAME.webp`, with names matching `data/fragrance-names.js`. They replace the numbered labels throughout the shop, galleries, search, favorites, comparisons, quiz, bundles and bag. Website names and bottle artwork use Latin letters only.

Created with the built-in image generation tool by editing each previously branded bottle photo. The bottle geometry, liquid color, black cap, label border, background and second reference bottle are preserved. The brand reads EDEN MUSK, and the old large reference number is replaced by the matching name. Sizes, ingredient details, prices and other source data are unchanged. These images remain packaging visualizations.

Final prompt template (CODE and NAME vary for each matching product):

> Edit only the printed label of the front main Eden Musk perfume bottle. Keep EDEN MUSK readable at the top of the cream label. Replace the large reference number CODE with NAME in elegant readable dark serif lettering. The final label shows EDEN MUSK on its first line and NAME beneath it. No old product reference number should remain on that label. Use English/Latin letters only, no Arabic letters. Preserve the small EXTRAIT DE PARFUM line and any actual volume marking. Keep the bottle shape, black cap, liquid color, glass, cream label shape and border, shadows, lighting, background, composition and second reference bottle exactly as in the input. Do not add decorations, badges, slogans or extra text. Spell NAME accurately without abbreviation. Photorealistic packaging-label edit, square image.
